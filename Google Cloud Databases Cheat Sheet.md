**Databases Types**

| Service                    | Type                                                 | Use when you see these keywords                                                                                  | Avoid when                                                                |
| -------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **Cloud SQL**              | Managed relational DB                                | MySQL, PostgreSQL, SQL Server, traditional app DB, simple migration, small/medium OLTP                           | Huge global scale, multi-region strong consistency, very high write scale |
| **AlloyDB for PostgreSQL** | High-performance PostgreSQL-compatible relational DB | PostgreSQL, demanding transactional workloads, enterprise-grade performance, PostgreSQL modernization            | Need MySQL/SQL Server, or globally distributed relational DB              |
| **Cloud Spanner**          | Globally scalable relational DB                      | Global relational DB, horizontal scale, strong consistency, mission-critical, multi-region, 99.999% availability | Small/simple app, cheap single-region relational DB                       |
| **Firestore / Datastore**  | Serverless NoSQL document DB                         | Mobile/web app, user profiles, catalogs, automatic scaling, flexible document model                              | Complex joins, relational schema, heavy analytical SQL                    |
| **Bigtable**               | NoSQL wide-column DB                                 | Petabytes, low latency, time-series, IoT, monitoring, ad-tech, huge key/value workloads                          | Relational queries, SQL joins, transactional business DB                  |
| **BigQuery**               | Analytics data warehouse                             | SQL over TB/PB data, reporting, BI, KPIs, historical analytics, data warehouse                                   | Real-time OLTP app database                                               |
| **Memorystore**            | In-memory cache/store                                | Redis/Valkey/Memcached, cache, sessions, leaderboard cache, sub-millisecond access                               | Permanent source of truth database                                        |
| **Cloud Storage**          | Object storage, not DB                               | Files, images, videos, backups, data lake, uploaded files                                                        | Need database queries/transactions                                        |
| **Filestore**              | Managed NFS file storage, not DB                     | Shared file system, lift-and-shift apps needing NFS                                                              | Database workload                                                         |

**Google Cloud database use cases**

| Service                    | Best use case                               | Example scenario                                                                        | Exam keywords                                                                |
| -------------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Cloud SQL**              | Traditional relational database             | A NestJS / PHP / Java app using MySQL, PostgreSQL, or SQL Server                        | MySQL, PostgreSQL, SQL Server, relational, managed DB, lift-and-shift        |
| **AlloyDB for PostgreSQL** | High-performance PostgreSQL                 | Existing PostgreSQL app needs better performance and availability than normal Cloud SQL | PostgreSQL-compatible, enterprise PostgreSQL, high performance               |
| **Cloud Spanner**          | Global relational database at massive scale | Global ecommerce orders, banking transactions, customer profiles across regions         | Global relational, strong consistency, horizontal scale, multi-region        |
| **Firestore / Datastore**  | Serverless NoSQL document database          | Mobile game player profile, shopping cart, user settings, flexible app data             | NoSQL, document DB, serverless, mobile/web app, automatic scaling            |
| **Bigtable**               | Huge low-latency NoSQL / time-series data   | IoT sensor data, game telemetry, monitoring metrics, ad-tech events                     | Petabyte scale, low latency, wide-column, time-series, high write throughput |
| **BigQuery**               | Analytics and reporting                     | Query 10 TB+ of game events, sales reports, user behavior KPIs                          | Data warehouse, analytics, SQL over TB/PB, BI, historical data               |
| **Memorystore**            | Cache / session / temporary fast data       | Store user sessions, leaderboard cache, rate-limit counters                             | Redis, Valkey, Memcached, cache, sub-millisecond access                      |
| **Cloud Storage**          | Object/file storage                         | Store images, videos, backups, uploaded files, raw data lake files                      | Files, objects, backups, archive, data lake                                  |
| **Filestore**              | Shared file system / NFS                    | Legacy app needs shared NFS storage between VMs or GKE pods                             | NFS, shared filesystem, POSIX, lift-and-shift                                |
